# relapse-log — 复发台账

> **记"第几次犯"，不写"再也不犯"。** 写了"再也不犯"的，通常第三次就犯了。
> 台账的价值在频次和场景，不在决心。

## 格式

```
### YYYY-MM-DD · 病名 · 第 N 次
- 场景：（当时在干什么）
- 触发：（哪句话/哪个动作把我带进去的）
- 代价：（他多花了多少时间、我错了多少）
- 修正：（下次遇到同样触发，具体做什么）
```

## 看台账的方法

不看"我改好了没有"，看两件事：

1. **同一条病的复发间隔**有没有变长
2. **触发场景**是不是从明显的变成隐蔽的

间隔没变长 = 没真改；场景变隐蔽 = 在进步，但不能松。
